### 📚 Fact of the day

**🐍 Python · 0.1 + 0.2**

Floats are stored in binary and aren't exact. Use math.isclose to compare them and decimal for money.

```python
import math
print(0.1 + 0.2 == 0.3)              # False
print(math.isclose(0.1 + 0.2, 0.3))  # True
```
