### 📚 Fact of the day

<!--FACT:START-->
**🐍 Python · pathlib and /**

In pathlib, paths are joined with the / operator — no manual slashes or os.path.join.

```python
from pathlib import Path
p = Path("mods") / "finsfish" / "config.json"
print(p.suffix)  # .json
```
