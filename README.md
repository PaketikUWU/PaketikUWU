### 📚 Fact of the day

<!--FACT:START-->
**🐍 Python · Generators save memory**

A generator expression doesn't build the whole list — it yields items one by one.

```python
total = sum(x * x for x in range(10_000_000))
print(total)  # no 10-million-element list
```
